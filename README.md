# cc_nurie — 3歳児向けぬりえアプリ

3歳児が熱中するクリエイティブな塗り絵 Web アプリ。
タップで塗れて、マジックブラシで虹色・キラキラに塗れて、完成すると絵が動き出します。

- 線画は どうぶつ・のりもの・しぜん の3系統×4点＝計12点
- インストール不要・完全静的サイト・外部通信なし
- スマホ縦持ち優先、テキストなしの全アイコン UI
- GitHub Actions で GitHub Pages に自動デプロイ

公開 URL（予定）: https://sakanayuki.github.io/cc_nurie/

## ドキュメント

設計の全容は **[DESIGN.md](./DESIGN.md)** を参照してください。
要件・UX 原則・線画12点の仕様・レイヤー構造・保存スキーマ・デプロイ構成を記載しています。

## 技術スタック

- Vite + TypeScript（フレームワークなし、実行時依存ゼロ）
- SVG（タップ塗り・輪郭線）＋ Canvas（クレヨン自由描画）の3層構造
- localStorage による塗りかけ自動保存
